## Кейсы последнего проекта

Работал Data Engineer в крупной розничной компании. Ниже две задачи, на которых построены демонстрационные проекты.

### 1. Миграция источников ETL: Greenplum → Hadoop/Hive

- **Задача:** перевести загрузки справочников на источники в Hadoop/Hive, не меняя структуру целевых таблиц PostgreSQL и порядок запуска следующих процессов.
- **Что сделал:** перенёс SQL-логику в PySpark, адаптировал Airflow DAG для запуска Spark-приложений, согласовал структуру результата с буферными таблицами, подготовил SQL-сверки старого и нового источников, отладил запуски в тестовой среде.
- **Результат:** среднее время выполнения одной из загрузок сократилось с 20 до 8 минут, то есть в 2,5 раза (−60%). Выполнены верхнеуровневые сверки четырёх пар исходных таблиц.
- **Стек:** Python, SQL, Airflow, PySpark, Greenplum, Hadoop, Hive, PostgreSQL, GitLab.
- **Демо:** [gp-to-hive-etl-migration](./gp-to-hive-etl-migration)

### 2. Перевод загрузки с Hive на S3

- **Задача:** изменить источник загрузки текущих цен: вместо Hive-таблицы читать дневные снимки в формате ORC из S3-совместимого хранилища.
- **Что сделал:** разработал изменения Spark-приложения и DAG: определение партиции по дате, проверка наличия данных, чтение ORC, сохранение существующей логики и загрузки в PostgreSQL.
- **Статус:** изменения разработаны и проходят проверку. Промышленное внедрение — следующий этап.
- **Стек:** Python, PySpark, Airflow, S3, ORC, PostgreSQL, Git.
- **Демо:** [hive-to-s3-snapshot-load](./hive-to-s3-snapshot-load)
